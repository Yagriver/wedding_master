# Chiara & Yago · Wedding website

First-pass responsive website for GitHub Pages. Plain HTML, CSS and JavaScript; no dependencies or paid services.

## Preview
Open `index.html` in a browser, or serve this directory with a local static server. Four bookmarkable views: `#home`, `#locations`, `#accommodation`, `#rsvp`.

## Publish on GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
Expected address after deployment: https://yagriver.github.io/wedding_master/

## Edit
- All three language dictionaries and page content: `app.js`.
- Colours, spacing and responsive rules: `styles.css`.
- Photos: `assets/`.
- Default language: Spanish. Browser preference is remembered where local storage is available.

## Scope and content to confirm
- Names, date (3 July 2027), venue names and addresses are provisional, copied from the reference below.
- Hotel recommendations, transport, schedule and dress code need confirmation.
- RSVP is explicitly closed. No names, invitation codes or responses are collected or stored. The described flow is planned, not yet implemented.
- Next phase: secure invitation lookup, persistent backend, editable household responses and private administration. Never place guest data or secrets in this public repository.
- No gift page. An optional honeymoon contribution can be added once wording and account details are supplied.
